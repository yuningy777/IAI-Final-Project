Presentation sample images (add your own files here)

For a smooth demo, prepare locally (do not commit large binaries unless your course requires it):

1. Two "easy" images: clear plastic bottle, obvious newspaper/cardboard mapped to paper.
2. Two "confusing" images: e.g. white foam vs paper; small rigid object vs glass_metal.
3. One typical error case from your error analysis (e.g. trash -> paper or trash -> glass_metal).

Then during the talk:
- Show a clean plastic example (correct).
- Show a confusing trash/paper example (limitations + tie-in to confusion matrix / top errors).

Run the UI from the project root:
  python demo/app.py

Open the printed local URL (usually http://127.0.0.1:7860) and upload files from this folder.
